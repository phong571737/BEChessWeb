# 05 — MongoDB Collections & Schemas

**Database name**: `chess`  
**Driver**: `mongodb` v7.0.0  
**Host**: MongoDB Atlas (cloud)

---

## Connection — `server/config/database.js`

Lazy singleton pattern:

```js
let client   = new MongoClient(env.MONGO_URI);
let database = null;

export async function connectDB() {
  if (database) return database;          // already connected
  await client.connect();
  await client.db("admin").command({ ping: 1 });  // verify connection
  database = client.db("chess");
  return database;
}

export function getDB() {
  if (!database) throw new Error("Database not connected!");
  return database;
}
```

`connectDB()` is called once at server startup. All subsequent code calls `getDB()` to access the db instance.

## Collection: `games` — Active game state

Used for: live board state, crash recovery, player name storage.

```ts
{
  _id:       string,          // equals gameID — custom string, NOT ObjectId
  gameID:    string,          // duplicate of _id (for query convenience)
  fen:       string,          // current board position in FEN notation
  pgn:       string,          // full PGN string including [Tag] headers
  lastMove: {
    from:      string,        // source square e.g. "e2"
    to:        string,        // target square e.g. "e4"
    promotion: string | null, // "q" | "r" | "b" | "n" | null
    uci:       string         // e.g. "e2e4" or "e7e8q"
  } | null,
  lastSeq:   number,          // monotonically increasing move counter
  WhiteName: string,          // display name for white player
  BlackName: string,          // display name for black player
  createdAt: Date,            // game creation timestamp
  updateAt:  Date             // last update timestamp (note: not updatedAt)
}
```

**Upsert strategy**: `updateOne({ _id: gameID }, { $set: state }, { upsert: true })`  
Every `saveGame()` call overwrites the full document.

**Note on `_id`**: Using the gameID string as `_id` avoids a separate unique index and makes lookups by gameID a primary key scan.

## Collection: `pgn_games` — Completed game archive

Used for: game history page, statistics, PGN review.

```ts
{
  _id:         ObjectId,              // auto-generated by MongoDB
  gameID:      string,                // reference to the originating active game
  pgn:         string,                // final PGN with all [Tag] headers and moves
  Result:      "1-0" | "0-1" | "1/2-1/2" | "*",
  White:       string,                // white player name
  Black:       string,                // black player name
  Date:        string,                // "YYYY.MM.DD" format (PGN standard)
  totalMoves:  number,                // number of half-moves (plies)
  createAt:    Date,                  // game start time (note: typo — not createdAt)
  endedAt:     Date,                  // game end time
  durationSec: number | null,         // (endedAt - createAt) in whole seconds
  endReason:   string,                // "resigned" | "draw_agreed" | "checkmate" | etc.
  winner:      "white" | "black" | null,  // null for draws
  loser:       "white" | "black" | null   // null for draws
}
```

**Insert strategy**: `insertOne(doc)` — records are immutable once written.  
**Sort order**: History endpoint queries `.sort({ createAt: -1 })` (newest first).  
**Delete**: `deleteOne({ _id: new ObjectId(id) })` — exposed via `DELETE /games/history/:id`.

## Model functions — `server/models/game.model.js`

|-------------------------------------|--------------|-----------------------------------------------------------------|
| `saveGame(gameID, state)`           | `games`      | upsert (`$set`)                                                 |

| `loadAllGame()`                     | `games`      | `find({}).toArray()`                                            |
| `removeGame(gameID)`                | `games`      | `deleteOne({ _id: gameID })`                                    |
| `endGame(doc)`                      | `pgn_games`  | `insertOne(doc)`                                                |

| `renamePlayer(gameID, color, name)` | `games`      | `updateOne({ _id }, { $set: { [color + "Name"]: name } })`     |

## Field name quirks

| Field                   | Quirk                                                                              |
|-------------------------|------------------------------------------------------------------------------------|
| `createAt`              | Typo (missing 'd') — present in `pgn_games`. Used as-is for backward compatibility.|
| `updateAt`              | Typo — present in `games`.                                                         |
| `WhiteName`/`BlackName` | PascalCase (inconsistent with other fields) — comes from PGN header convention.    |
| `_id` in `games`        | String (gameID), not ObjectId — intentional.                                       |
| `_id` in `pgn_games`    | ObjectId (auto-generated) — standard.                                              |
